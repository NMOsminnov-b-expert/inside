# Реестр предметной области

Записи о том, что учитывает и чем оперирует система: понятия, поля, а в
дальнейшем документы, процессы и справочники.

## Устройство

Одна запись — один файл. Имя файла латиницей: кириллица в путях по-разному
отображается в терминалах и `git status`.

    knowledge/concepts/    понятия: типы объекта оценки, виды объекта
                           имущества, блоки карточек, основные термины
    knowledge/fields/      поля: название, где встречается, тип значения,
                           единица, обязательность, этап заполнения

## Состав записи

| Часть | Что содержит |
|---|---|
| `id` | устойчивый идентификатор, по нему на запись ссылаются |
| `вид` | понятие или поле |
| `термин` | название так, как оно выглядит на экране |
| `синонимы` | как ещё называют то же самое |
| `определение` | заполняется человеком |
| `статус` | `черновик` до подтверждения человеком, затем `подтверждён` |
| `источник` | откуда взято: макет, закон, внутреннее решение |
| `снято` | дата, когда сведения сняты с макета |
| `встречается` | объект, блок, пример экрана, типы записи |

У поля дополнительно: `тип_значения`, `единица`, `значений_в_списке`,
`строка_таблицы`, `обязательное_в`, `этап_заполнения`.

## Откуда взялось начальное наполнение

Записи сняты с работающих экранов макета, а не из кода: скрипт открывает
карточки и выписывает то, что на них видно. Поэтому у каждой записи указан
экран, на котором её можно проверить.

Все записи начального наполнения имеют статус `черновик`: содержание снято
машиной, определения не выдуманы и оставлены пустыми.

Справочники значений в реестр пока не переносятся.

## Команды

    python tools/knowledge/migrate_from_mockup.py   пересобрать из макета
    python tools/knowledge/check_registry.py        сверить реестр с макетом

Сверка открывает каждый названный в записях экран и проверяет, что подпись
там действительно есть. Запись, которая не подтвердилась, попадает в список.

## Что делать с записью

1. Написать определение своими словами.
2. Указать этап заполнения: создание карточки, сбор документов, осмотр,
   дозаполнение после осмотра, оценка.
3. Проверить синонимы.
4. Сменить статус на `подтверждён`.

## Правила ведения

Термин, помеченный звёздочкой на экране, обязателен — звёздочка в название
не входит, она записывается в `обязательное_в` с указанием места.

Тип объекта оценки и вид объекта имущества — разные понятия, даже когда
называются одинаково: «Гражданское здание» как тип записи и как объект
имущества ведутся отдельно.

Одно название поля — одна запись со списком мест, где оно встречается.
