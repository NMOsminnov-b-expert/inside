# Код макета — архитектура и пометки

Подгружается при работе в `app/`. Перенесено из корневого CLAUDE.md
30.10.2026; см. также `app/README.md`. Правила графа: `izolyaciya-moduley`,
`kartochka-zemelnogo-uchastka-isklyuchenie-iz-izolyacii-moduley`,
`pometki-dlya-servernoy-versii`.

## Архитектурные правила

- `modules/*` → `kernel` — можно; `modules/*` → `modules/*` — **нельзя**;
  `kernel|shell|pages` → `modules/*` — **нельзя**, кроме `kernel/registry.js`.
- Ядро не знает ни одного типа ОЦ и ни одного вида ОИ.
- Модули ОЦ (`apartment`, `residential-house`, `civil`, `land-plot`,
  `vehicle`, `mechanisms`) изолированы друг от друга, кроме дверей ниже.
  `civil` — единый тип «Нежилое здание» (с 28.09.2026 в него слито
  «Производственное строение»; тип считает `civil/card/typology.js` по
  внутренней площади литер; `#/oc/production/...` ведёт в `civil` через
  `manifest.aliases`).
- Двери между модулями — осознанные исключения:
  1. Земельный участок — `land-plot/oi/land/*`, переиспользуют остальные
     четыре модуля (участок у всех типов ОЦ один и тот же).
  2. ТС «база + модуль» — объект имущества в любом типе ОЦ (23.09 и
     28.09.2026): дверь `vehicle/card.js` (`vehicleOiCard`,
     `vehicleCardMeta`); стили — реестр ядра (`styleHref`), форма в `.ts-host`.
  3. Механизмы и оборудование — объект имущества в любом типе ОЦ и
     самостоятельный ОЦ (28.09.2026): дверь `mechanisms/card.js`
     (`mechOiCard`, `mechCardMeta`, `createMechOi`, миграции); стили —
     `mechanisms/module.css`, граница `body .mu-stack`.
  4. Литера нежилого здания — объект имущества в любом типе ОЦ (13.10.2026):
     дверь `civil/card.js` (`buildingOiCard`, `newBuildingOi`,
     `migrateLiterKinds`); стили — `civil/module.css`, правила `.lk-*`,
     `.kc*`, `.zn*` без привязки к модулю.
- Разрешённые пути — `.dependency-cruiser.cjs` (`npm run lint:arch`);
  меняется правило — править и его.
- Изменение, нарушающее эти правила, — предупредить явно, прежде чем делать.

## Пометки для серверной версии

Осознанное упрощение макета, которое на сервере потребует отдельного
решения (личные настройки, файлы, автор и время действий, права доступа,
объёмные выборки), помечается комментарием:

    // ДЛЯ СЕРВЕРНОЙ ВЕРСИИ: <что упрощено>

и дальше — чем это станет на сервере и какие есть варианты. Решать за
серверную команду не нужно — назвать развилку и её последствия.
