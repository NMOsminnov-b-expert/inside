# «Осмотр» в браузере (PWA) — для iPhone без установки

То же приложение, что на Android, — те же экраны, описи, папки, отчёты и архивы, — только
открывается в Safari и ставится значком на экран «Домой». Сборка — `tools/web/build.sh`, папка
`shared/build/dist/wasmJs/productionExecutable`.

## Установка на iPhone (один раз, минута)

1. Нужен **iOS 18.2 или новее** (Настройки → Основные → Об этом устройстве). Старее — страница
   сама скажет, что браузер не подходит: приложение собрано в WebAssembly со сборкой мусора, а её
   Safari умеет с 18.2.
2. Откройте адрес «Осмотра» в **Safari**.
3. «Поделиться» → **«На экран „Домой“»** → «Добавить». Дальше открывать — значком.
4. Первый раз нажмите «Снять» — Safari спросит доступ к камере: «Разрешить». Если отказали:
   «Аа» в адресной строке (или Настройки → Safari) → Камера → Разрешить.

Значком — обязательно: приложению с экрана «Домой» Safari даёт **постоянное хранилище** (его не
стирают, даже если долго не открывать), квота — до ~60 % диска. Во вкладке Safari «Осмотр» сам
напомнит об этом.

## Чем отличается от Android и от приложения для iPhone

| | Android / iPhone-приложение | PWA |
|---|---|---|
| Где лежат снимки | память телефона, видны в «Файлах», копия в «Фото» | только внутри приложения (хранилище Safari); наружу — **архивом** |
| Камера | своя, серия | своя, серия; ФОТО/ВИДЕО, 4:3/16:9, сетка, зум кнопками — где Safari даёт |
| Ручные настройки камеры, 0.6× системной камеры | есть (Android) | нет: браузер не даёт выдержку и ISO |
| Как получается снимок | фотосъёмка: вспышка, обработка производителя, EXIF (дата, камера) | кадр из видеопотока камеры: без обработки iPhone (HDR, Deep Fusion), без EXIF; дата съёмки — в имени файла; разрешение — сколько отдаёт поток (на iPhone не проверено) |
| Сканер документов | есть (Android) | нет |
| «Поделиться» фото **в** «Осмотр» из мессенджера | есть | нет (Safari не принимает); вместо — «Из галереи» |
| Контакт из телефонной книги | есть | вводится руками |
| Документы (PDF, Excel, Word, сканы) | есть | есть: выбор файлов, просмотр PDF со страницами, миниатюрами и поворотом — pdf.js, работает без сети |
| Геометка в адресе | есть | есть: Safari спросит доступ к геопозиции, нужен https |
| Контакт через «Поделиться» | есть | нет (Safari не принимает) |
| Архив «Сохранить» | в «Загрузки» | «Сохранить» → окно «Поделиться» → «Сохранить в Файлы» |
| Без сети | работает | работает после первого открытия с сетью |

**Главное правило для PWA: выгружать архив после каждого выезда.** Удалить значок с экрана
«Домой» — удалить и все снимки.

## Что говорит документация Safari (сверено 26.10.2026)

| Возможность | С какой версии | Как учтено |
|---|---|---|
| WebAssembly GC (без неё приложение не запускается) | Safari / iOS 18.2 | проверка в `index.html`, понятный отказ |
| Хранилище | с экрана «Домой» — постоянное по запросу `persist()`, вне очистки; квота до 60 % диска | `persist()` при запуске; во вкладке Safari — подсказка добавить на экран «Домой» |
| Камера в приложении с экрана «Домой» | iOS 13.4; на iOS 17.4–17.6 у части iPhone — чёрная картинка (WebKit 273938), в iOS 18 не воспроизводится | через 6 с без кадров — совет перезапустить |
| Запись видео (MediaRecorder, MP4 H.264/AAC) | iOS 14.3; в 18.4 beta 1–3 — неиграющие MP4 (WebKit 288459, исправлено) | `video/mp4` без кодеков, запись одним куском |
| «Поделиться» файлами (архив → «Сохранить в Файлы») | iOS 14 (`canShare({files})`); «Сохранить в Файлы» — пункт системного окна для файлов | проверка `canShare`; откажет — архив скачивается и ложится в «Файлы → Загрузки»: сохранится в любом случае |
| Сжатие кадра в Worker (OffscreenCanvas, `convertToBlob`) | Safari 16.4 | без него — сжатие на месте |
| Фонарик (`torch`) | с iOS 17 | кнопка — только если камера его объявила |
| Зум (`zoom`) | Safari 17 объявляет `zoom` в возможностях камеры; по отзывам, на части iPhone его нет | кнопки — только если камера объявила зум; нет — без кнопок (общий вид — отойти) |

## Временно — с ноутбука, через его точку доступа

Пока нет постоянного адреса, «Осмотр» раздаёт ноутбук: `tools/web/hotspot.sh start` (повторный запуск обновляет
раздачу), один раз — `tools/web/hotspot.sh firewall` (Windows спросит права). Включает мобильную точку доступа
Windows, поднимает nginx на `192.168.137.1` с той же настройкой `deploy/pwa/osmotr-pwa.conf` и свой корневой
сертификат (на IP-адрес настоящий не выдают; закрытый ключ — только в `~/.config/osmotr-hotspot` в WSL).

На iPhone: подключиться к точке доступа ноутбука → Safari → `http://192.168.137.1/` → «Загрузить профиль» →
Настройки → «Профиль загружен» → Установить → Основные → Об этом устройстве → Доверие сертификатам →
включить «Осмотр — ноутбук». Профиль ставит сертификат и значок «Осмотра» (веб-клип на весь экран), Apple ID
не нужен. Ноутбук нужен для установки и обновлений; после первого открытия «Осмотр» работает без сети.

**Проверить на живом iPhone:** значок из профиля открывается как приложение и получает то же постоянное
хранилище, что добавленный вручную («На экран „Домой“») — снимки на месте после перезагрузки телефона.
**При переезде на постоянный адрес** данные с ноутбучного адреса сами не переедут: выгрузить архивы.

## Сервер

Приложение — статические файлы; сервер ничего не считает и данных не получает.

- **Только https** (камера, микрофон и работа без сети в Safari без https не включаются).
  Исключение — `localhost` для проверки на компьютере.
- `.wasm` — с типом `application/wasm` (иначе браузер грузит медленнее или отказывает).
- Кэш: `index.html`, `sw.js`, `manifest.webmanifest` — `no-cache` (иначе телефоны не узнают о
  новой сборке); остальное можно кэшировать надолго — имена `.wasm` меняются с каждой сборкой.
- Сжатие: `gzip`/`brotli` для `.wasm` и `.js` (14 МБ → ~4 МБ при первом открытии).

Готовая настройка — [deploy/pwa/](../deploy/pwa/): `osmotr-pwa.conf` (типы, сжатие, кэш,
заголовки безопасности) и `site.conf` (пример сайта: подставить домен, сертификат, папку). Выложить:

```bash
tools/web/build.sh
sudo rsync -a --delete shared/build/dist/wasmJs/productionExecutable/ /srv/osmotr/
sudo cp deploy/pwa/osmotr-pwa.conf /etc/nginx/ && sudo cp deploy/pwa/site.conf /etc/nginx/sites-available/osmotr
sudo ln -sf /etc/nginx/sites-available/osmotr /etc/nginx/sites-enabled/ && sudo nginx -t && sudo systemctl reload nginx
```

Проверить ту же настройку здесь, ничего не ставя в систему: `tools/web/https-check.sh` поднимает
nginx с `osmotr-pwa.conf` по https (самоподписанный сертификат) во временной папке, проверяет
заголовки (типы, сжатие, кэш, `Permissions-Policy`, HSTS) и прогоняет пути матрицы через него.

Обновление: выложить новую сборку целиком. Телефон получит её при следующем открытии с сетью
(служебный работник скачивает всё заново) и покажет со второго открытия.

## Проверка на компьютере

```bash
tools/web/build.sh
(cd shared/build/dist/wasmJs/productionExecutable && python3 -m http.server 8099 --bind 127.0.0.1) &
node tools/web/matrix.mjs                # все пути × Chromium и WebKit × 3 размера × 2 ориентации × 2 темы
node tools/web/scenarios.mjs --list      # какие варианты использования чем проверены
```

WebKit под Linux — тот же движок, что Safari, но без MediaRecorder (видео и голос там не
проверяются — путь говорит это прямо) и с программной отрисовкой (скорость спуска — не о iPhone).

## Что проверить на живом iPhone (матрица этого не заменяет)

1. Открывается на iOS 18.2+; на iOS ниже — сообщение «браузер не подходит», а не пустой экран.
2. «На экран „Домой“» → открыть значком → нет адресной строки, «Осмотр» в переключателе приложений.
3. Камера: разрешение спрашивается один раз; размер снимка (выгрузить архив папки, на компьютере — свойства .jpg) — сколько точек даёт поток и хватает ли для осмотра; серия из 20 касаний подряд — все кадры в папке,
   приложение не закрылось; 0,5×/1×/2× — есть ли кнопки зума и фонарик (зависит от версии iOS).
4. Видео 30 с со звуком → в папке `.mp4`, играется; запись прерывается звонком/сворачиванием —
   то, что записано, сохранилось.
5. Свернуть посреди серии и вернуться — камера снова работает.
6. Авиарежим → открыть значком → опись, съёмка, архив работают.
7. Архив описи → «Сохранить» → «Сохранить в Файлы» → открыть в «Файлах» — внутри те же папки,
   что на Android.
8. Импорт `.xls`/`.xlsx` из «Файлов» и из почты.
9. Перезагрузить телефон → всё на месте.
