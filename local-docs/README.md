# Локальные копии документов

Сюда просмотрщик макета копирует прикреплённые файлы, если в меню «+» выбрать
«Копировать файлы в папку…» и указать эту папку (Chrome или Edge).

Всё, кроме этого файла, в `.gitignore`: документы реальные, в репозиторий и в
сеть они не уходят. Копии нужны, чтобы по ним можно было пройтись и собрать
примеры для разбора. Сами файлы для макета хранятся в IndexedDB браузера
(`app/kernel/localFiles.js`), папка — только копия.
