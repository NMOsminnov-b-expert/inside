# Корректировка карточки ОЦ «Гражданское здание»

Работа 09–10.09.2026 по указаниям Осминова Н. Начата на ветке `осмотры`
(коммиты `e34eab7`…`ab018ec`), продолжена на ветке
`карточка-гражданского-здания` (`f116e58`…`e3ffb5a`).

Порядок работы, установленный пользователем:

* область — ОЦ «Гражданское здание» и карточка его литеры; остальные типы ОЦ
  правятся только по отдельному указанию («сейчас над другими карточками
  работают ребята с команды»);
* быстрые точечные правки, **коммит после каждой**; полные прогоны проверок и
  отчётность — по отдельной отмашке;
* подписи меняются только по прямой просьбе.

Здесь собрано, **что и почему** сделано. Подробности каждой правки — в теле
соответствующего коммита.

---

## 1. Код ЕНИ

| Что | Коммит |
|---|---|
| Маска по ходу ввода, несколько кодов через запятую | `e34eab7` |
| Свёрнутый показ, хвост заменяет блок между тире | `7c5fe2a` |
| У записи список кодов, а не один (`eniList`) | `fe0c22b` |
| Код нового объекта имущества больше не инкрементируется | `63b08f0` |

Тире ставит интерфейс, человек их не печатает. Допустимые длины 13/15/18 цифр
(`kernel/eniField.js`, `ENI_GROUPS`). Свёртка вида «1-47-56-1681-(3510, 3511)»
живёт в `kernel/eniFold.js`.

**Почему код ОИ не растёт.** Счётчик выдавал «следующий свободный», и его всё
равно правили руками: код объекту имущества присваивает Кадастр, а не макет.
Новый объект получает код самой записи. Функция `nextEni` из
`civil/data/store.js` убрана — её больше никто не вызывает.

## 3. Собственники и пользователи

| Что | Коммит |
|---|---|
| Строки вместо модалок, доля у собственника | `e8275a9` |
| Блоки: номер, наименование, доля | `7e7154f` |
| Компактный вид: блок в одну строку, подписи сверху списка | `bbd9030` |
| Доля дробью — «1/2», «2/3» | `63b08f0` |
| Поле ПУД — документ, по которому указана доля | `6128e1c` |
| Подсказки по всем прикреплённым документам, поиск, вид списка | `e925d0c` |

**Дроби.** Их пишут в правоустанавливающих документах, и переводить в проценты
руками — лишняя работа и лишняя ошибка. `parseShare` переводит дробь в проценты
(1/2 → 50), сумма считается по обеим записям, а сама дробь хранится как
написали. Знак процента у дробной записи скрывается: «1/2 %» читалось бы как
полпроцента.

**ПУД.** Список подсказок НЕ сужается по виду документа: долю указывают и по
правоустанавливающему, и по правоудостоверяющему, а вид проставляют не всегда.
Отфильтруй по виду — нужный документ не всплыл бы. В подсказки попадают и
документы объектов имущества; поиск идёт и по виду с датой («акт» находит
«Гос. акт на землю»). Название колонки осталось «ПУД» по решению пользователя.

## 4. Местоположение (блок 02 карточки ОЦ)

| Что | Коммит |
|---|---|
| Новый блок: область, район, город, микрорайон, улица, дом, квартира, GPS, адрес | `b18b19b` |
| Адрес записи — редактируемый, вставленная строка разбирается по полям | `b18b19b` |
| Область, район и город — выпадающими списками из справочников | `8fae274` |
| Адрес переносит строку, а не режет | `ab018ec` |

Адрес и координаты убраны из карточек ОИ: адрес у записи один, держать его
частями в каждом ОИ значило собирать одно и то же по кускам. Разбор строки —
`kernel/address.js`, `parseAddress`, по маркерам «обл.», «р-н», «г.», «мкр.»,
«ул.», «д.», «кв.».

**Значение вне справочника не теряется.** Адрес приходит из Кадастра и из
вставленной строки, где пишут как придётся («обл. Чуй» против «Чуйская
область»). Такой вариант добавляется в список пунктом «— нет в справочнике»:
иначе присвоение `el.value` молча ничего не делало бы. Общий помощник
`setAddrField` — и для разбора строки, и для ответа Кадастра.

**Открытый вопрос:** связывать ли списки в цепочку (район по области, город по
району). Сейчас списки плоские.

## 5. Кадастр: адрес по коду ЕНИ

| Что | Коммит |
|---|---|
| Запрос к порталу, разбор ответа | `905dbd8` |
| Подстановка по кнопке, а не автоматически | `58ffc18` |
| Пустое сообщение не занимает место | `8772f9e` |
| Свой прокси спрашивается первым, отказы — в консоль | `fd95dd8` |
| Кнопка во всех пяти типах ОЦ | `47a928c` |

**Почему по кнопке.** Автоматическая подстановка не давала убрать адрес вовсе:
сотрёшь поля, тронешь код — и они заполнены снова.

**Почему прокси.** Портал `cadastre.kg` не отдаёт `Access-Control-Allow-Origin`,
и браузер не даёт прочитать ответ. Два обхода: свой прокси
(`tools/cadastre/proxy.py`) и прокси Live Server. Свой спрашивается первым —
когда поднят, отвечает сразу; когда не поднят, браузер отказывает мгновенно.
Обратный порядок стоил шести секунд на каждое нажатие.

## 6. Сохранение введённого

| Что | Коммит |
|---|---|
| Данные переживают перезагрузку (localStorage) | `713f6fe` |
| Записи всех типов ОЦ, состояние карточки, правки без «Сохранить» | `1fba4f4` |
| Формат карточки распространён на все пять типов | `2744f9a` |
| Просмотрщик, боковое меню, панель фильтров | `da57356` |

Один снимок JSON под ключом `inside:data:v1`, источники регистрируются сами
(`kernel/persist.js`). По решению пользователя сохраняются **только ОЦ и ОИ**;
в справочниках, учреждениях, архиве и реестре документов оставлены пометки, как
включить.

Поля формы пишутся в запись **сразу, на `change`**, а не по кнопке «Сохранить»:
иначе часть введённого не переживала перезагрузку.

**Свёрнутое меню применяется до первой отрисовки** — единственным синхронным
скриптом в `app.html`: `shell.js` модуль, а модули исполняются после разбора
страницы, и меню успевало отрисоваться в полную ширину и схлопнуться на глазах.

**Значения фильтров реестра не сохраняются** — они живут в адресе, чтобы ссылку
на подборку можно было переслать; сохраняется только то, открыта ли панель.

## 7. Карточка литеры: площади и этажи

| Что | Коммит |
|---|---|
| Подсказка про автораспределение видна, колонка «Авто» подписана | `d2fab4d` |
| Площадь застройки выведена из автораспределения | `63b08f0` |
| Названия площадей по техпаспорту | `2c8e977` |
| Сверка показывает величину расхождения, кнопка рядом | `e83ccd3` |
| Отметка «авто» — замком вместо галочки | `63f86c1` |
| Числа с разделением разрядов | `5068f98` |

**Названия.** «Общая по техпаспорту» → «Площадь по внешним замерам» (с
подсказкой, что берётся со страницы «Характеристика строений и сооружений»),
«Площадь застройки» → «Площадь по внутреннему обмеру». Ключи данных
(`areas.tp`, `areas.build`, `floorList.area/.areaBuild`) прежние.
Прежняя оговорка «застройка — она же по наружным замерам» снята как
противоречащая.

**Застройка не распределяется** — это площадь среза сверху, этажи на неё чаще
всего не влияют. Признак живёт у самой колонки (`auto` в `AREA_FIELDS`), а не
проверкой имени в трёх местах.

**Расхождение словами** — «не хватает 12,30 м²», а не «−12,30»: знак ещё нужно
истолковать. Янтарь, а не красный: несошедшиеся площади — обычное состояние
незаконченной работы.

**Замок вместо галочки.** Галочка читалась как «этаж выбран», хотя выбора там
нет. Под замком остался обычный `checkbox` — обработчики и клавиатура; значок
нарисован маской, а не эмодзи.

**Числа.** `kernel/numField.js` держит показ и хранение раздельно: на экране
«1 000 000,00», в записи «1000000,00». В фокусе разряды снимаются — править
число с неразрывными пробелами неудобно.

## 8. Карточка литеры: прочее

| Что | Коммит |
|---|---|
| Пристройки — таблицей вместо трёх списков | `9daeb9c` |
| Колонка уточнения убрана, литера компактной | `5f85a5e` |
| Оформление таблицы — как в справочниках | `c6c7942` |
| Ячейки не обводятся при наведении | `11d54f7` |
| Материалы — мультивыбор с поиском; блок аренды вниз | `46ab3b5` |
| Списки тихие и свои, вместо системных | `701e4a2` |
| Подсказка литеры от литеры строения | `e3ffb5a` |
| Отметка расхождения убрана, «Цоколь/подвал», «Класс ОИ» | `08bfc67` |

**Пристройки.** Было три списка — лоджии, балконы, террасы — с одним названием
и площадью. Веранду или тамбур записать было некуда, литеру — тоже, а материалы
нигде не хранились. Стала таблица по образцу страницы техпаспорта
«Характеристика строений и сооружений»: литера, вид, фундамент, стены, кровля,
площадь. Старые данные переносятся; название элемента становится видом «Иное» с
этим текстом.

**Оформление — из раздела «Справочники»** (`pages/dicts`): поле в ячейке без
рамки, столбцы разделены линиями, новая строка добавляется плюсиком в самой
таблице. Рамка появляется только при работе с ячейкой: при наведении строка
вспыхивала десятком прямоугольников.

**Свои выпадающие списки.** Браузерный `<select>` рисует ОС — синяя подсветка,
чужие отступы. Заменён на `.ms` (`kernel/multiSelect.js`), одиночный и
множественный. Открытие привязано к самой ячейке: общий обработчик карточки
вешается один раз, а строки таблицы появляются после этого.

**Подсказка литеры** строится от литеры строения: строчная буква плюс номер,
первая пристройка без номера («Ж» → ж, ж1, ж2). Из составной литеры («Г, Г1»)
берётся первая заглавная.

## Что осталось открытым

* **Полный прогон `tools/checks/run.py` не делался** — по решению пользователя.
  Заведомо требуют внимания: `check_eni.py` (проверял инкремент кода ОИ,
  который отменён) и сценарии, затронутые сохранением состояния панелей.
* **Правки не распространены на остальные четыре типа ОЦ** — кроме кнопки
  Кадастра (`47a928c`) и подсказки в поэтажке (`d2fab4d`). Общие изменения
  ядра (`numField`, `areaList`, `foldSearch`, тосты) действуют везде.
* **Область в адресе** заполнена только в данных гражданского; из-за этого
  `ocAddressTop` собирает адрес в разном порядке у разных типов.
* **Улица и дом остались в карточках ОИ** у четырёх модулей — решение «в ОИ их
  не будет» выполнено только в civil.
* **Поле `oi.dis`** («расхождение ТП/фото») осталось в данных и в фильтре
  реестра, хотя отметка из карточки убрана.
* **Связывание списков адреса** в цепочку (район по области) — не решено.
* Записи в граф знаний по этой работе не вносились.
