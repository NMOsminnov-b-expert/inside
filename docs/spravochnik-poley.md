# Справочник полей макета

Состав данных макета: какие поля есть у объекта оценки и у каждого вида
объекта имущества, в каком типе объекта оценки они встречаются и в каком
блоке карточки находятся.

Состав снят с экранов макета, а не с кода: в документ попало то, что видит
оценщик, и теми же словами. Разделы — по РД 50-34.698-90 «Описание
информационного обеспечения»: сначала состав и структура, затем перечни
полей, затем справочники и указатель.

Ключ поля — атрибут разметки (`data-…`), по нему поле ищется в макете.

## 1. Структура: объект оценки → объект имущества

### 1.1. Типы объектов оценки

| Тип объекта оценки | Модуль | Витрина для просмотра |
|---|---|---|
| Жилое здание (квартира) | `apartment` | `#/oc/apartment/oc-ap-all` |
| Жилое здание (дом) | `residential-house` | `#/oc/residential-house/oc-rh-all` |
| Гражданское здание | `civil` | `#/oc/civil/oc-cv-all` |
