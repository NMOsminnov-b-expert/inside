## Договорённости, уже зафиксированные (не переоткрывать)

- **ЕНИ**: хранится голыми цифрами, тире расставляет интерфейс при показе (Л1.3).
- **Числа**: дробные — разряды пробелом и 2 знака после запятой; целые — только
  разряды; годы и коды — без разделителей (Л1.2).
- **Дерево**: верхний уровень — участок, литеры лежат внутри него (Л2.1).
- **Особенности ≠ заметки**: механики похожи, но это разные сущности, объединять
  некорректно. Особенность — текстовая запись без чекбокса, в будущем получит
  влияние на оценку (Л3.6).

## Обозначения состояния

- `НОВОЕ` — в коде такого нет вовсе.
- `ЧАСТИЧНО` — что-то есть; указано, что именно и чего не хватает.
- `ПРАВКА` — поведение есть, но работает не так.
- `СДЕЛАНО` — закрыто в этой сессии.
