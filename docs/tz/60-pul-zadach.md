либо ждут уточнения. Держим их здесь, а не в переписке, чтобы формулировка не

## 1. Несколько кодов ЕНИ в таблицах — правило свёртки

**Откуда**: заметки команды (Даниил), уточнение пользователя 05.09.2026 —
«при отображении нескольких ЕНИ в интерфейсе таблицы одинаковые части повторяем,
разные перечисляем через запятую».

**Что уже сделано**: столбец реестра «Коды ЕНИ ОИ» собирает коды объектов
имущества записи и сворачивает их так: общее начало пишется один раз, дальше в
скобках через запятую идут различающиеся хвосты —
`1-47-56-1671-(0010, 0020, 0150)` (`app/kernel/eniFold.js`).

**Что уточнить перед следующим шагом**: формулировка «одинаковые части
повторяем» допускает и другое прочтение — общее начало печатается у каждого
кода, а не выносится один раз:

```
сейчас:            1-47-56-1671-(0010, 0020)
второе прочтение:  1-47-56-1671-0010, 1-47-56-1671-0020
```

Различие видно на узких столбцах: первый вариант короче вдвое, второй читается
без разбора скобок и копируется целыми кодами. Нужен выбор пользователя; заодно
решить, где ещё показывать свёрнутые коды кроме реестра (шапка карточки ОЦ,
печатные формы).

## 2. Переносы текста в таблице перечня ОИ

**Откуда**: замечание пользователя 05.09.2026 со снимком — «Административн…
здание» рвётся посреди слова.

**Что мешает**: нужно решение, что делать с длинным наименованием литеры —
переносить по словам с ростом строки, обрезать многоточием с подсказкой или
сокращать по словарю («административное» → «админ.»). Каждый вариант меняет
высоту строки перечня.
