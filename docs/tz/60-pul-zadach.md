# Пул задач

Задачи, которые названы, но в работу пока не взяты: либо отложены сознательно,
либо ждут уточнения. Держим их здесь, а не в переписке, чтобы формулировка не
терялась и её можно было взять в работу без переспрашивания.

Формат записи: что сделать, откуда пришло, что мешает начать прямо сейчас.

## 1. Несколько кодов ЕНИ в таблицах — правило свёртки  ✔ решено

**Откуда**: заметки команды (Даниил), уточнение пользователя 05.09.2026.

**Решение пользователя 05.09.2026**: свёрнутый вид — общее начало один раз,
различающиеся хвосты в скобках через запятую:

```
1-47-56-1671-(0010, 0020, 0150)
```

Второй рассматривавшийся вариант (перечисление целых кодов
`1-47-56-1671-0010, 1-47-56-1671-0020`) отклонён: столбец реестра узкий, а
свёрнутая запись вдвое короче. Хвосты сортируются по возрастанию — в скобках их
читают как перечень номеров.

Сделано в `app/kernel/eniFold.js`, показывается столбцом «Коды ЕНИ ОИ» в реестре
объектов, сторожится `tools/checks/check_address.py`.

**Осталось решить**: показывать ли свёрнутые коды где-то ещё кроме реестра —
в шапке карточки ОЦ и в печатных формах. Пока не показываются.

## 2. Переносы текста в таблице перечня ОИ

**Откуда**: замечание пользователя 05.09.2026 со снимком — «Административн…
здание» рвётся посреди слова.

**Что мешает**: нужно решение, что делать с длинным наименованием литеры —
переносить по словам с ростом строки, обрезать многоточием с подсказкой или
сокращать по словарю («административное» → «админ.»). Каждый вариант меняет
высоту строки перечня.
