# Пропущенные поля в реализованных карточках

Выжимка из [40-otchet-pokrytie-tz.md](40-otchet-pokrytie-tz.md) под конкретный
вопрос: **каких полей не хватает в тех карточках, что уже сделаны** — квартира,
строение (литера), земельный участок. Типы, к которым не приступали (транспорт,
мебель, оборудование, сооружения), и этапы II–IV сюда не входят.

Как проверялось: состав интерфейса собирался из подписей полей, заголовков
блоков, разделов и шапок таблиц — не из комментариев (поиск по всему тексту
давал ложные «есть»). Отдельно сверялись поля, которые **заполняются в данных,
но не выводятся ни в одной карточке** — самый надёжный признак поля, потерянного
при перестройке.

---

## 1. Потеряны в интерфейсе: данные есть, показать негде

Генератор их заполняет, в логе действий у них есть подпись, а в карточке поля
нет. Значение существует — увидеть и поправить нельзя.

| Поле | Пример значения из данных | Где нет |
|---|---|---|
| **Особенности** (`features`) | «Нестандартная высота потолков на 2 этаже — 3.20 м» | во всех карточках строения |
| **Комментарий** (`comment`) | «Капитальный ремонт кровли — 2018 г.» | во всех карточках строения и в квартире |
| **Права на строение** (`rights`) | «Собственность» | только в production; в остальных четырёх модулях поле есть |

«Особенности» — прямое требование ТЗ для жилого дома и нежилых: нестандартная
высота потолков, нефункциональная планировка, дополнительные территории, выход
за пределы красной линии.

---

## 2. Квартира

Этап А закрыт полностью: серия, площади по ПУД и ТП, права, этажность,
положение на этаже, лоджии и балконы списками с площадями, планировки,
документы, год постройки.

Нет полей **этапа Б (осмотр)**:

| Поле ТЗ | Комментарий |
|---|---|
| Наличие электрификации | — |
| Наличие газификации | — |
| Наличие центрального отопления | отдельного поля нет; есть отметка «Центральное» в мультивыборе «Отопление» — **без шкалы** «да / нет / проходят рядом / отсутствуют в районе» |
| Наличие центрального водоснабжения | — |
| Наличие автономного отопления | та же отметка в мультивыборе, отдельного поля со шкалой нет |
| Тип автономного отопления: уголь, газовая колонка, электрокотел, тепловой насос | — |
| Прочие особые параметры: пристройка, кладовка, сушилка, парковка, гараж и документы на них; участки в собственности; отдельный вход, перепланировка, тёплый пол | текстового поля под это нет (см. §1 — «Комментарий» потерян) |

---

## 3. Строение (жилой дом, нежилое, производственное)

Этап А закрыт: статус и тип строения, литера, год постройки, площади по ПУД, ТП,
факту и застройки, права, этажность с развёрткой (подвал, цоколь, надземные,
мансарда), конструктивный тип мансарды, лоджии и балконы списками, фундамент и
материал стен в конструктиве, высота.

Нет полей **этапа Б**:

| Поле ТЗ | Комментарий |
|---|---|
| Электрификация, газификация, центральное отопление, водоснабжение, автономное отопление — по шкале «да / нет / проходят рядом / отсутствуют в районе» | ни одного; есть только мультивыбор «Отопление» (центральное, автономное, печное, радиаторы, тёплые полы) — он отвечает на «что стоит», а не на «подведено ли» |
| Наличие центральной канализации | — |
| Наличие септика | — |
| Санузел внутри дома/здания | — |
| Тип автономного отопления | — |
| Тип утепления: пенопласт, пеноплекс, базальт, пенополиуретан | «Утепление» в карточке — элемент **износа**, а не материал |
| Примечание голосом | — |
| Внутренняя планировка «по кнопке» | есть у квартиры и жилого дома, **нет у гражданских и производственных** |

Материал кровли отдельным полем не нужен: он закрыт конструктивом («Кровля»:
металл, мягкая, плоская, шифер).

Для нежилых дополнительно (в ТЗ помечено «не ранее чем через 3 месяца»):

| Поле ТЗ | Комментарий |
|---|---|
| Общая / полезная / сдаваемая площадь **по этажам** (подвал, цоколь, 1-й, 2-й, 3-й и выше, мансарда) | есть только общий список арендных площадей |
| Стоимость сдаваемых площадей по этажам, аренда в сом/мес | — |
| Класс здания расчётом (высота × кран-балка × конструктив × полы, карманы 0,15–1,00) | поля-множители есть, автоприсвоения класса нет |
| Смотровые ямы, ж/д пути | — |
| Генплан единым атрибутом базы (одна кнопка на все строения) | планы прикрепляются к каждому ОИ |
| Документы атрибутом дома/базы, доступные из любого строения | документы у каждого ОИ свои |

## 4. Земельный участок

Самая полная карточка. После правок 04.09.2026 закрыты: назначение по
правоудостоверяющему документу, три площади и застроенная, права, сервитуты с
комментарием, категория земель, инженерные сети, координаты, зона и микрорайон,
удалённость от райцентра, рельеф, полив, почва, бонитет, каменистость, ранг
благоустройства, вспомогательные постройки.

| Поле ТЗ | Комментарий |
|---|---|
| План участка **из госакта** — отдельная подгрузка | отдельного поля нет, прикрепляется общим списком документов |
| План участка **из техпаспорта** — отдельная подгрузка | отдельного поля нет |
| Комментарий к местоположению голосом (к трём параметрам) | — |

Убраны вашим решением 04.09.2026 (расхождение с ТЗ осознанное): наличие
автономного отопления; наличие, тип и площадь построек — их заменил список
вспомогательных построек.

**Хвост:** генератор синтетики всё ещё заполняет убранные `autonomousHeating`,
`buildings`, `buildingType`, `buildingArea`. Значения лежат в данных и нигде не
показываются — всплывут при выгрузке, стоит подчистить.

## 5. Общие поля всех типов

| Поле ТЗ | Состояние |
|---|---|
| Уникальный номер с правилом присвоения (номер учреждения + номер типа объекта) | нет; есть ЕНИ и внутренний идентификатор |
| Контактные данные центрального аппарата госоргана (имя, телефон) | нет |
| Срок экономической жизни (заполняет ЦОД) | нет |
| GPS-координаты **фото** | нет; координаты есть у объекта и участка, у снимка — нет |
| ФИО (ID) осмотрщика | есть — назначается в ответственных |

---

## 6. Поля, потерянные в отдельных модулях

Не требования ТЗ, а расхождения макета: одна и та же литера в разных типах ОЦ
описывается разным набором полей.

| Поле | Где есть | Где нет |
|---|---|---|
| Права на строение | apartment, residential-house, civil, land-plot | **production** |
| Лоджии, балконы, террасы | apartment, residential-house, civil | **production**, land-plot |
| Износ конструктивных элементов | civil, production | apartment, residential-house, land-plot |
| Арендные площади | civil, production | остальные |
| Категория ОИ (класс) | apartment, residential-house, civil, production | **land-plot** |
| Планировки | apartment, residential-house | civil, production |
| Температурный режим, усиленность конструкции | production | civil (по ТЗ нужны и там) |
| Блок «Местоположение» и GPS в форме ОЦ | land-plot | остальные четыре |
