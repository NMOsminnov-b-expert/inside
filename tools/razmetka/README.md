# Разметка документов

Настольная программа (Windows, .NET 10 WPF) для разметки: страницы документа
(техпаспорт, госакт…) и снимки блоков системы на одном полотне, рамки на
графах документа и стрелки к полям системы. Заменяет ручную правку
«Перенос документов в систему.html» (`tools/docs/build_tp_v_sistemu.py`).

Данные проектов — реальные документы, в git не кладутся: проект — папка,
которую пользователь выбирает сам (например, в `Примеры доков/` или
`local-docs/`, обе в `.gitignore`).

## Сборка

Нужен .NET SDK 10. Прав администратора не нужно: SDK ставится в папку
пользователя —

    powershell -c "iwr https://dot.net/v1/dotnet-install.ps1 -OutFile $env:TEMP\di.ps1; & $env:TEMP\di.ps1 -Channel 10.0 -InstallDir $env:LOCALAPPDATA\Microsoft\dotnet -NoPath"

    build.cmd          :: dist\Razmetka.exe — один файл, .NET внутри

`Razmetka.exe` запускается на любом Windows 10/11 x64 без установки и без
администратора.

## Качество картинок

Потерь нет (требование 29.09.2026):

* файл картинки ложится в проект как есть — байт в байт, без пересжатия и
  уменьшения; картинка из буфера обмена — PNG;
* страницы PDF рисуются в 300 dpi (PNG), на полотне стоят в прежнем размере
  110 dpi — подробность видна при увеличении и в экспорте;
* экспорт — PNG в разрешении самой подробной картинки разворота (пиксель
  исходника — в пиксель выгрузки; потолок 16000 точек по стороне, 120 Мп).

Картинки, вставленные до 29.09.2026, были уменьшены до 3000 точек и частью
сохранены в JPEG 88 — такие заменяются исходником («Заменить», подгонка по
двум точкам сохранит рамки).

Резкость: разрешение — по каждому монитору (`app.manifest`, PerMonitorV2),
текст интерфейса — по пикселям экрана (`TextFormattingMode=Display`), тень
у карточек — отдельной подложкой: эффект на самой карточке мылит текст.

## Проект на диске

    <папка проекта>/
      razmetka.json    главы, развороты, слои, рамки, связи, заметки
      images/          картинки; имя файла — хэш содержимого

Формат (`Model/Project.cs`) устроен так, чтобы слои не путались:

* у каждого слоя, рамки и связи постоянный `id`; стрелка ссылается на рамку,
  рамка — на слой по `id`, а не по месту в списке;
* порядок наложения — порядок в `layers` (первый — нижний);
* обрезка не трогает картинку: `crop` — видимая часть в пикселях исходника;
* рамка хранится в пикселях исходника своего слоя — перенос, масштаб и
  обрезка слоя её не сбивают.

Несохранённые правки раз в 5 секунд пишутся черновиком в
`%LOCALAPPDATA%\Razmetka\drafts`; при следующем открытии проекта программа
предлагает их восстановить.

## Окно

Раскладка — по практике `interfeys-razmetki-dokumentov-klavishi-palitra-komand-inspektor-po-vyb`
в графе знаний (Figma UI3, Excalidraw, CVAT, Label Studio, Rossum, Fluent 2):

* **шапка** — проект (меню: новый, открыть, недавние, экспорт), где я сейчас
  («глава › разворот», щелчок — перейти), поиск по связям, фильтр по блоку
  системы, палитра команд, проверка с числом замечаний, экспорт, сохранение;
* **слева** — развороты по главам (у разворота страница, число связей, «без
  описания», точка — есть замечания проверки; глава сворачивается щелчком) и
  слои текущего разворота;
* **в центре** — полотно; инструменты — панелью внизу по центру, режим
  (новая связь, обрезка, подгонка, заметка) — плашкой сверху: шаг, что
  сделать, как выйти;
* **под полотном** — вкладки разворотов текущей главы, как листы Excel и
  страницы CorelDRAW: слева выбор главы и ‹ ›, «+» — новый разворот после
  текущего, правая кнопка — вставить до / после, сдвинуть, удалить,
  перетаскивание — порядок, двойной щелчок — переименовать; справа —
  «Один / Подряд»: в режиме «Подряд» все развороты проекта столбцом по главам,
  прокрутка ведёт за собой текущий, двойной щелчок или Enter — править,
  Ctrl+колесо — крупнее;
* **справа** — свойства выбранного: связь, слой, несколько слоёв, заметка;
  без выбора — разворот, глава и перечень связей разворота;
* без проекта — стартовый экран с недавними проектами.

Основа элементов — встроенная тема Windows 11 (`ThemeMode` в `App.xaml`),
поверх — свои кисти и стили.

## Клавиши

Все действия — в одном реестре (`Ui/Commands.cs`, состав —
`MainWindow.Commands.cs`): из него работают клавиши, палитра команд, меню
правой кнопки, подсказки кнопок и шпаргалка. **F1** — шпаргалка, **Ctrl+K** —
все команды, развороты и связи одним поиском. Одиночные клавиши — только когда
фокус на полотне; раскладка не важна (V и «М» — одна клавиша).

| Что | Клавиши |
|---|---|
| Инструменты | V — выбор, H — рука (пробел — на время), L — новая связь, N — заметка, M — лупа, C — обрезать |
| Связи | Tab / Shift+Tab — следующая / предыдущая, Enter — описать, R — переложить стрелку, P — закрепить подсказку |
| Выбранное | Enter — править (обрезка — готово), стрелки — сдвиг (Shift — на 10; без выбора — полотно), Delete, Ctrl+D — копия, F2 — переименовать, Esc — выйти из режима, снять выбор |
| Слои | Ctrl+] / Ctrl+[ — выше / ниже (с Shift — наверх / вниз), Ctrl+Shift+L — закрепить, Ctrl+Shift+H — скрыть |
| Развороты | PageDown / PageUp или, как в Excel, Ctrl+PageDown / Ctrl+PageUp — следующий / предыдущий, Ctrl+Shift+PageDown / PageUp — глава, Ctrl+P — перейти, Ctrl+Shift+N — новый после текущего, Alt+← / Alt+→ — сдвинуть, Ctrl+Shift+V — «Один / Подряд»; в списке — Alt+↑/↓ порядок, Delete |
| Вид | Shift+1 (или Ctrl+0) — весь разворот, Shift+2 — выбранное, Shift+0 — 100 %, Ctrl+± , Ctrl+\ — только полотно, F6 — фокус по областям |
| Проект | Ctrl+S, Ctrl+O, Ctrl+N, Ctrl+E — экспорт HTML, Ctrl+Z / Ctrl+Y, Ctrl+V — картинка из буфера, Ctrl+F — поиск по связям (Enter / Shift+Enter), F8 / Shift+F8 — замечания проверки |

## Разметка подряд

L — обвести графу на странице документа, затем поле на снимке системы;
карточка описания открывается у стрелки сама. В полях — подсказки из уже
введённого в проекте (графы — из той же главы, поля системы — из всего
проекта; ↓/↑ и Enter), ниже — комментарий: как переносится, оговорки,
вопросы (виден в таблице связей, в подсказке и в экспорте). Вид связи один —
«переносится», выбирать его не нужно. **Enter** — готово, **Shift+Enter** —
готово и сразу следующая связь.

## Мышь

| Действие | Как |
|---|---|
| Выбрать слой / добавить к выбору | щелчок / Shift+щелчок |
| Выбрать несколько | обвести по пустому месту |
| Перенос, размер | перетаскивание; углы — размер с пропорциями; Alt — без прилипания |
| Масштаб, сдвиг | колесо у курсора; средняя кнопка, пробел или H + перетаскивание; Shift+колесо — вбок |
| Меню действий | правая кнопка на картинке, таблице, стрелке, заметке или пустом месте |
| Панель у выбранного | над выбранной связью или картинкой — главные действия значками |
| Подсказка связи | щелчок по стрелке, номеру или строке таблицы; P — закрепить у номера |
| Описать связь | двойной щелчок по стрелке, номеру или строке таблицы |
| Обрезка | двойной щелчок по фото или C; ручки — край, внутри — сдвиг картинки; Enter / Esc — готово |
| Рамка связи, путь стрелки | у выбранной связи: край рамки — перенос, углы — размер; отрезок стрелки — тянуть поперёк; излом, выпрямить, стороны — правая кнопка по стрелке или раздел «Стрелка» справа |
| Замена фото | «Заменить», затем две точки на прежней (бледной) картинке и те же на новой — рамки и обрезка подгоняются |
| Вставка фото | Ctrl+V, перетаскивание файлов на окно; папку проекта на окно — открыть |
| Документ из PDF | страницы «1-3, 5» — развороты новой или текущей главы |
| Таблица связей | «Под картинками» / «Справа колонкой» — в свойствах разворота; «Разделить», «Слить» — у выбранной таблицы |

История правок (кто, когда, что) пишется в проект на каждый шаг; у выбранной
связи последние изменения — в свойствах.

Номера связей сквозные по главе: после любой правки глава перенумеровывается
подряд. Стрелка, у которой концы оторвались от рамок (слой перенесли,
обрезали, растянули), перекладывается сама в том же шаге отмены.

## Перенос готовой разметки

    python tools/docs/export_razmetka.py

собирает проект «Примеры доков/Перенос документов в систему — разметка» из
глав сборщика `build_tp_v_sistemu.py` вместе с ручными правками рамок и
стрелок (блок box-edits готового HTML).

## Проверка

Ключ `--script <файл.json>` прогоняет сценарий теми же путями, что мышь и
клавиатура (`ScriptRunner.cs`), снимает окно в PNG и выгружает проект в JSON
для сверки; журнал — рядом, `<файл>.log`. Шаги: `size`, `open`, `sheet`,
`addImages`, `fit`, `zoom`, `click`, `dbl`, `drag`, `key`, `select`, `save`,
`shot`, `dump`, `wait`, `clickLink`, `dragLinkSeg`, `dragFrame`, `bendLink`,
`button`, `cmd` (команда реестра по id), `palette` (запрос и выполнить первую
строку), `closeOverlays`, `focus`, `keyWin` (клавиша с учётом фокуса),
`overflow` (что выходит за окно), `flow` (режим «Подряд»), `scrollFlow`.
