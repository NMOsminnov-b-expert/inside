# Граф проекта

Настольная программа (Windows, WinUI 3, .NET 10) для просмотра и правки
графа `knowledge/`: поиск, фильтры, граф в 2D и 3D, список, карточка записи
с правкой полей, меток, пунктов и связей, история записи из git, выгрузка и
загрузка графа файлом. Пока окно открыто, файлы, поменянные снаружи
(редактор, `graph.py`, `git pull`, переключение ветки), подхватываются сами.

Запись в карточке сохраняется тем же форматом, что пишет
`tools/knowledge/graph.py`, байт в байт — какой бы инструмент ни сохранил
файл, git увидит только смысловые изменения.

## Сборка и запуск

    tools\graf\build.cmd          → tools\graf\dist\Graf.exe

.NET и Windows App SDK — внутри папки `dist`, ставить ничего не нужно, прав
администратора тоже. Ярлык «Граф проекта» на рабочем столе ведёт на
`dist\Graf.exe`.

Проект — папка, в которой лежит `knowledge/`. Какой открыть: ключ
`--root <папка>`, иначе последний открытый, иначе поиск вверх от текущей
папки. Сменить — кнопкой проекта слева вверху (недавние, Ctrl+O — другая
папка, Ctrl+R — все проекты) или перетащив папку в окно. Список проектов и
места узлов графа хранятся на машине, в `%LOCALAPPDATA%\Graf`, — не в
проекте и не в `.claude`.

## Оформление

По Human Interface Guidelines Apple (запись графа
`dizayn-programmy-graf-proekta-po-hig-apple`): панель инструментов в три
группы, сегменты вместо вкладок и кнопок-переключателей, боковая панель с
группами под треугольником и строками с галочкой справа, карточки
(inset grouped) с подписями разделов заглавными, «Отменить / Готово» при
правке записи, переключатели iOS, капсулы поиска и меток. Палитра светлой и
тёмной темы — значения iOS в `App.xaml` (кисти `Hig*`), элементы —
`Views/Hig.cs` (строка, карточка, раздел, заголовок группы, капсула,
переключатель, сегменты, кнопки).

## Управление

| | 2D | 3D |
|---|---|---|
| Колесо | масштаб у курсора | ближе к точке под курсором |
| Левая по пустому | сдвиг | вращение вокруг точки |
| Правая, Shift+левая | сдвиг | сдвиг |
| WASD, стрелки | сдвиг | полёт; Q/E — вниз/вверх; Shift — быстрее |
| Тянуть узел | соседи идут следом — так распутывают граф; отпущенный узел закрепляется (точка) | то же |
| Щелчок / двойной щелчок / F | выбрать / приблизить / к выбранному | то же |
| Правая по узлу | меню: открыть, показать ближе, распутать вокруг, закрепить/открепить | то же |
| Home | весь граф | весь граф |

Ctrl+1/2/3 — граф, 3D, список; Ctrl+F — поиск (Enter — следующее найденное);
Ctrl+N — новая запись; Ctrl+S — сохранить; F1 — подсказка по управлению.

Слева — вкладки «Оглавление» и «Фильтры». Оглавление — запись
`knowledge/project/oglavlenie_grafa.py`, разделы — её связи «раздел» на карты
разделов `knowledge/project/karta_razdela_*.py`, якоря — связи «якорь» из
карты: раздел раскрывается шевроном, якорь открывает запись, метка ставит
фильтр. Фильтры (вид, статус, метки) узлы не
прячут: отсеянные на графе тёмные и прозрачные, раскладка не меняется, в
строке состояния — «на графе N, отобрано M». В режиме «Список» — сортировка
по виду, заголовку, дате добавления или изменения (даты — из git, у
незакоммиченных — время файла) и кнопка направления; обе даты — в строке.

Поверх графа слева сверху — раскладка и окрестность. «Свободно» — силовая
раскладка; «Острова» — записи одного вида в своей области; «Темы» —
острова по сообществам связей (Louvain, сообщество всегда связно — поправка
Leiden): записи, тесно связанные между собой, независимо от вида. Отдалить
острова дальше вида «весь граф» (Home) — они сворачиваются в круги с числом
записей, связи между островами — одной линией с числом. При отдалении
подписаны только центры — самые связанные записи. «Окрестность 1/2/3» —
выбранная запись и соседи на столько шагов.

В карточке на вкладке «Связи»: связи сюда — обратным именем вида
(«реализует» с той стороны читается «реализовано в»), ниже — «Похоже по
смыслу»: соседи записи из индекса semsearch (без уже связанных), «+» ставит
связь «относится к». Нет выгрузки — «Возможно связано»: кандидаты по общим
соседям и по сходству текста. «Проверка» — числа графа (части связности, записи без
связей, центры), ошибки и замечания к наполнению группами; то же считает
`graph.py check` и `stats` (`Model/Quality.cs` ↔ `tools/knowledge/quality.py`).

## Граф кода и связи по смыслу

Данные — выгрузки в `.graf/` проекта (вне git), пересобираются пунктом
«Ещё» → «Обновить граф кода и связи по смыслу»:

* `.graf/semantic.json` — `tools/knowledge/semantic_export.py` (Python из
  окружения semsearch): средний вектор каждой записи из индекса по смыслу,
  у записи — до трёх ближайших со сходством от 0,84. На графе — пунктир
  «похоже по смыслу»; раскладка «Смысл» ставит рядом похожие записи (тянут
  только такие связи).
* `.graf/code.json` — `tools/knowledge/code_export.py` из индекса CodeGraph
  (`.codegraph/codegraph.db`, только чтение): файлы кода вне `knowledge/`,
  их функции и классы, связи файл → файл (вызывает, импортирует, ссылается,
  создаёт) с числом случаев.

Переключатель «Знания · Код» над графом. В режиме «Код» узел — файл,
остров — модуль (`app/modules/civil`, `app/kernel`, `tools/checks`…), слева —
список модулей с галочками (снятый модуль приглушается). Карточка файла:
функции и классы (щелчок — VS Code на этой строке), «Зависит от» и «От него
зависят», записи графа знаний о файле или его папке (папка `code`). Из
записи о файле кода — «Открыть в графе кода».

## Раскладка в покое

В покое граф стоит: правка текста, новая связь, обновление с диска не
двигают узлы, которые уже на месте. Новые узлы рассчитываются при
неподвижных старых и въезжают на место. «Разложить заново» (кнопка со
стрелкой по кругу) пересчитывает всё и открепляет закреплённые.

## Выгрузка и загрузка

Кнопка со стрелкой в правой части панели: «Выгрузить граф в файл…» — один
JSON со всеми записями; «Загрузить граф из файла…» — сначала сравнение (новые,
изменятся, совпадают), запись — только по кнопке «Загрузить». Записи,
которых нет в файле, остаются; удалить их — отдельная галка. Откатить
загрузку — через git.

## Проверки

    Graf.exe --root <папка> --selftest <отчёт.txt>
    Graf.exe --root <копия графа> --script <сценарий.json>

Готовые сценарии с проверкой результата — `tools/graf/checks/*.json`, запуск
`python tools/graf/checks/run.py [имя …]` на собранной программе (dist) и копии
графа во временной папке; провал — ошибка в журнале сценария, код выхода или
новая запись в `%TEMP%\graf-crash.log`.

`--selftest` — каждая запись пишется заново и сравнивается с файлом, плюс
выгрузка→загрузка не должна ничего поменять. `--script` — шаги из
`ScriptRunner.cs` (select, search, mode, pull, orbit, motion, export,
import, external, shot, dump, islands on/off/topics, islandstat, zoom,
quality, check, paneltab, perf), журнал — рядом с файлом сценария. Шаг
`perf` (kind: pan2d, zoom2d, camera, pull, layout, relayout, hover, orbit3d,
fly3d, idle; s — секунды) пишет покадровый замер: частота, интервалы p50–p99,
рывки, время рисования, сборки мусора, выделения по участкам кадра, долгие
кадры с операциями рядом. Вывод — CanvasSwapChainPanel, кадр рисуется в такте
экрана; тяжёлый счёт раскладки — в фоновом потоке. Сценарии
гонять на копии графа: они правят файлы.

Движение на снимке не видно — поведение во времени проверяется шагом
`motion`: сдвиг узлов за заданное время, число кадров, идёт ли раскладка.

## Устройство

* `Model/` — чтение и запись записей (`Literal`, `Store`), схема папок
  (`Record`), выгрузка (`Exchange`), настройки машины (`Settings`),
  выгрузки графа кода и связей по смыслу (`Derived`).
* `MainWindow.Code.cs` — режим «Код», пересборка выгрузок, переход в VS Code.
* `Views/GraphView.cs` — полотно (Win2D): раскладка, камера 2D/3D, мышь и
  клавиши, отрисовка. `RecordPanel.cs` — карточка записи.
* `MainWindow` — окно: проект, поиск, фильтры, режимы, диалоги.

`dotnet publish` без упаковки не кладёт в выпуск `Graf.pri` и `*.xbf`, и окно
падает при запуске; их докладывает цель `CopyXamlResourcesToPublish` в
`Graf.csproj`.

## Ход индексов

Справа в строке состояния — полоски «CodeGraph» и «По смыслу». Прогон
обоих индексов — `tools/hooks/reindex.py`: сам после каждого коммита (хук
`tools/hooks/post-commit`, подключение — `git config core.hooksPath
tools/hooks`) или «Ещё» → «Обновить граф кода и связи по смыслу». Ход он
пишет в `.graf/index-status.json`, программа опрашивает файл раз в две
секунды и сравнивает коммит прогона с HEAD: идёт — бегущая полоска и
стадия (у поиска по смыслу — число файлов); актуален — зелёная; отстаёт
(построен на прежнем коммите) — оранжевая; ошибка — красная; «прогон
оборвался» — прогон числится идущим, а процесса уже нет. Подробности — в
подсказке у полоски; журнал — `.graf/reindex.log`. По окончании прогона
выгрузки графа кода и связей по смыслу перечитываются сами.
